**Server-Sent Events** (**SSE**) sind eine unidirektionale Kommunikation vom Server zum Client („Einbahn“). Man nimmt sie für kurze Nachrichten.

## Eigenschaften

[[Datei:Server-Sent_Events.svg|mini|Unidirektionale Kommunikation vom Server zum Client]]

- unidirektionale Kommunikation (Server zu Client)
- Echtzeit-Updates
- textbasierte Daten (meist JSON)
- einfach zu implementieren

## Einsatz

SSE sind gut geeignet für Benachrichtigungen und Newsfeeds.
