Das **Glossar** enthält kurze Begriffserklärungen.

; Binär
: Das Gegenteil von binär ist Text.
; Cluster
: Ballung, Konglomerat
; Datenmodell
: die Datenstruktur
; Ephemeral
: statuslos
; Idempotent
: Mehrfaches Ausführen hat dieselbe Wirkung wie einmaliges Ausführen (z. B. [[HTTP-Methoden#PUT|PUT]] und [[HTTP-Methoden#DELETE|DELETE]]).
; JMS
: Java Messaging, wie ein kleiner [[MQTT]]-Server
; Kafka
: Apache Kafka für Streams, wie [[MQTT]] für große Anwendungen
; Kontext
: Bezug, Zusammenhang (siehe auch [[C4-Modell#Kontextdiagramm|Kontextdiagramm]], [[Context (KI)]])
; LeoCloud
: Cloud mit einem Staging-Server, einem Entwicklungsserver und einem Production-Server; persönliche Bereiche dort sind [[#Namespace|Namespaces]]
; Modell
: ein vereinfachtes Abbild der Realität; Fokus auf die Datenstruktur, aber vereinfacht
; Multistage Docker Build
: mehrere Images, die später zu einem gemergt werden
; Namespace
: ein persönlicher Bereich in der Cloud (hier: [[#LeoCloud|LeoCloud]])
; Objekt-Identität
: In der objektorientierten Programmierung: Speicherort, Hash (siehe [[JPA#Primärschlüsselstrategien|Primärschlüsselstrategien]])
; Persistenz
: dauerhaft speichern
; [[Proprietär]]
: firmenspezifisch
; Submodul
: ein Unterprojekt, das nur im Projekt instanziert wird und nur im Vaterprojekt bearbeitet werden kann (z. B. ein eigenes Repo für Rules und Skills eines [[KI-Agent|KI-Agenten]])
; Swimlanes
: Verantwortungsbereiche
; Transient
: flüchtig
; User-Federation
: Weiterleiten der Anmeldung, z. B. bei Google oder Amazon anmelden
; Zustandslos
: ohne Vorgeschichte; HTTP ist zustandslos, weil der Server keine Vorgeschichte hat
