Das **C4-Modell** (C4-Schema) beschreibt Software mit Diagrammen auf vier Abstraktionsschichten: Context, Containers, Components und Code.

## Abstraktionsschichten

1. [[#Kontextdiagramm|Kontextdiagramm]]: das System in seiner Umgebung
2. Containerdiagramm: die Anwendungen und Datenspeicher, aus denen das System besteht
3. Komponentendiagramm: die Komponenten innerhalb eines Containers
4. Code: Klassen usw.

## Kontextdiagramm

Das Kontextdiagramm zeigt, in welchem Zusammenhang ([[Kontext]]) das Projekt steht.
